# ARBS icon (ARBS-H copy)

`arbs.ico` is the ARBS app icon (16, 20, 24, 32, 48, 64 and 256 px), copied unchanged from the ARBS repository
(`arbs-project/arbs`, folder `branding/`, file `ico/arbs.ico`, commit `dcdc4485f9`). Made by the ARBS project,
GPL-3.0-or-later. The drawing sources, the generator and the other sizes (tray, web, Android) are in that folder.

ARBS-H uses it for `sunshine.exe` and the bundled tools (`cmake/compile_definitions/windows.cmake`) and for the
installer and uninstaller (`packaging/windows/arbs-h/arbs-h.iss`). Tray and web copies live under
`src_assets/common/assets/*/public/images/` (`arbs-*`). The older Apollo / Vibepollo icon files stay in this tree.
